## О проекте

`Sonoluminiscence` — исследовательский проект по вычислительной физике, посвящённый численному моделированию акустически индуцированного коллапса газового пузырька в жидкости.

Проект рассматривает упрощённую постановку однопузырьковой сонолюминесценции:

- замкнутый осесимметричный сосуд с жидкостью;
- гармонический акустический источник на границе;
- параболический отражатель внутри сосуда;
- газовый пузырёк в акустическом поле;
- численная проверка того, может ли локальное акустическое воздействие привести к сильному термомеханическому коллапсу пузырька.

Проект не моделирует напрямую излучение фотонов. Вместо этого он ищет режимы, в которых динамика пузырька приближается к физическим предпосылкам однопузырьковой сонолюминесценции: сильное предварительное расширение, быстрое схлопывание, высокий нагрев газа, большое давление внутри пузырька и высокая скорость стенки пузырька.

---

## Физическая идея

Сонолюминесценция связана с тем, что газовый пузырёк в жидкости под действием акустического поля периодически расширяется и схлопывается. В фазу пониженного внешнего давления пузырёк растёт, а затем, когда давление меняется, окружающая жидкость сжимает его обратно.

Если схлопывание достаточно быстрое, энергия движения жидкости концентрируется в малом объёме газа. Газ сжимается, его температура и давление резко возрастают. При достаточно сильном коллапсе возможна световая вспышка.

В этом проекте проверяется следующий вопрос:

> Может ли выбранная геометрия акустического резонатора создать такие точки, где пузырёк испытывает сильный термомеханический коллапс?

## Общая вычислительная цепочка

Полный расчёт строится как связка нескольких физических и численных блоков:

```text
геометрия сосуда
  -> сетка
  -> акустическая задача
  -> поле давления P(r, z)
  -> потенциал Горькова U_G(r, z)
  -> выбор точек-кандидатов
  -> давление в точке пузырька P_b
  -> внешнее давление p_inf(t)
  -> уравнение Keller-Miksis
  -> R(t), dR/dt, T_g(t), p_g(t)
  -> метрики коллапса
  -> CSV / VTK / визуализация
```

Смысл цепочки:

1. Строится осесимметричная геометрия сосуда.
2. Внутри сосуда задаётся параболический отражатель.
3. По геометрии строится сетка.
4. В жидкости решается акустическая задача.
5. По полю давления строится карта акустического воздействия.
6. По потенциалу Горькова выбираются физически осмысленные точки-кандидаты.
7. В каждой точке берётся локальное комплексное давление.
8. Это давление подаётся в модель пузырьковой динамики.
9. Для пузырька решается нелинейная задача радиального движения.
10. По результатам считаются метрики коллапса и выбирается лучший кандидат.

## Основные физические модели

### 1. Акустическое поле

Акустическое поле в жидкости рассматривается в линейном гармоническом приближении. Давление представляется через комплексную амплитуду.

Основная акустическая задача сводится к уравнению Гельмгольца:

```text
Delta P + k^2 P = 0

k = omega / c_l
omega = 2 * pi * f
```

где:

| Обозначение | Смысл |
|---|---|
| `P` | комплексная амплитуда акустического давления |
| `k` | волновое число |
| `omega` | угловая частота |
| `f` | частота источника |
| `c_l` | скорость звука в жидкости |

Граничные условия:

| Граница | Физический смысл | Условие |
|---|---|---|
| Жёсткая стенка | жидкость не проходит через стенку | нулевая нормальная скорость |
| Отражатель | жёсткая внутренняя граница | нулевая нормальная скорость |
| Источник | гармоническое движение стенки | заданная нормальная скорость |

Расчёт выполняется в меридиональном сечении `(r, z)`, поскольку сосуд, отражатель и источник считаются осесимметричными.

---

### 2. Потенциал Горькова

Одна только карта давления не даёт полного критерия выбора точки для пузырька. Большая амплитуда давления показывает, где пузырёк может сильно возбуждаться радиально, но не показывает, является ли эта область акустически подходящей для размещения пузырька.

Поэтому в проекте используется потенциал Горькова. Он нужен как дополнительная физическая диагностика акустического поля.

Сила, связанная с потенциалом Горькова, записывается как:

```text
F_G = - grad U_G
```

где:

| Обозначение | Смысл |
|---|---|
| `U_G` | потенциал Горькова |
| `F_G` | акустическая радиационная сила |
| `grad U_G` | пространственный градиент потенциала |

В проекте потенциал Горькова используется для выбора точек-кандидатов. Итоговая идея такая:

- поле давления показывает, где пузырёк получает сильное внешнее воздействие;
- потенциал Горькова помогает выбрать акустически осмысленную область;
- окончательное решение принимается только после расчёта динамики пузырька.

---

### 3. Связь акустики с пузырьком

После выбора точки-кандидата `x_b` из акустического поля берётся локальная комплексная амплитуда давления:

```text
P_b = P(x_b)
```

Далее из неё строится внешнее давление, действующее на пузырёк:

```text
p_inf(t) = p_0 + A_b * cos(omega * t + phi_b)

A_b = |P_b|
```

где:

| Обозначение | Смысл |
|---|---|
| `p_inf(t)` | внешнее давление жидкости около пузырька |
| `p_0` | статическое давление |
| `A_b` | локальная амплитуда акустического давления |
| `phi_b` | фаза локального давления |
| `omega` | угловая частота источника |

Это главный узел связи между акустическим расчётом и пузырьковой динамикой.

---

### 4. Радиальная динамика пузырька

Для расчёта радиального движения пузырька используется модель Keller-Miksis.

Она выбрана вместо базового уравнения Rayleigh-Plesset, потому что при сильном схлопывании скорость стенки пузырька может становиться заметной относительно скорости звука в жидкости. Модель Keller-Miksis учитывает поправки, связанные со сжимаемостью жидкости и конечной скоростью распространения акустических возмущений.

Расчёт отслеживает:

| Величина | Смысл |
|---|---|
| `R(t)` | радиус пузырька |
| `dR/dt` | скорость стенки пузырька |
| `T_g(t)` | температура газа внутри пузырька |
| `p_g(t)` | давление газа внутри пузырька |

По этим величинам затем определяется, является ли режим слабым сжатием, умеренным коллапсом или сильным кандидатом на сонолюминесценцию.

---

### 5. Газовая модель

В текущей версии газ внутри пузырька моделируется как сухой аргон.

Это упрощение. В реальном эксперименте могут быть воздух, водяной пар, растворённые газы, диффузия через границу пузырька, испарение, конденсация и химические реакции. Здесь эти эффекты пока не включены, чтобы выделить основной механизм: сжатие пузырька, рост давления и нагрев газа.

Газовая модель включает:

- уравнение состояния газа;
- hard-core поправку к объёму;
- баланс энергии газа;
- теплоотвод через эффективный тепловой слой.

Hard-core объём нужен, чтобы не допускать нефизического бесконечного сжатия газа.

Теплоотвод через эффективный тепловой слой используется как приближение. Во время медленных стадий пузырёк успевает обмениваться теплом с жидкостью. Вблизи коллапса процесс становится быстрее, и сжатие газа приближается к адиабатическому: тепло просто не успевает уйти из пузырька.

## Критерии классификации кандидатов

Для каждого кандидата вычисляются основные метрики.

### Основные метрики

| Метрика | Смысл |
|---|---|
| `R_min` | минимальный радиус пузырька |
| `R_max` | максимальный радиус пузырька |
| `T_max` | максимальная температура газа |
| `p_g_max` | максимальное давление газа |
| `U_max` | максимальная скорость стенки пузырька |
| `K_R` | степень сжатия относительно начального радиуса |
| `K_exp` | степень расширения относительно начального радиуса |
| `K_range` | полный динамический диапазон радиуса |
| `M_l` | отношение скорости стенки к скорости звука в жидкости |
| `K_h` | запас до hard-core радиуса |

### Используемые пороги

Механический критерий коллапса:

```text
K_R >= 8
K_exp >= 5
K_range >= 40
M_l >= 0.03
K_h >= 1.2
```

Тепловой критерий:

```text
T_max >= 8000 K
p_g_max >= 1e8 Pa
```

Строгий SBSL-кандидат должен пройти оба блока критериев:

```text
mechanical_collapse_ok = true
thermal_heating_ok = true
thermomechanical_luminescence_candidate = true
```

Эти пороги используются как рабочая численная диагностика. Они не означают прямого расчёта светового излучения, но позволяют выделять режимы, где сжатие и нагрев уже достаточно сильны.

---

## Статусы режимов

| Статус | Смысл |
|---|---|
| `SoftCompression` | слабое сжатие или почти линейные колебания |
| `ModerateCollapse` | выраженный нелинейный коллапс, но не строгий SBSL-кандидат |
| `MechanicalCollapseOnly` | механический коллапс есть, но тепловой критерий не выполнен |
| `ThermoMechanicalLuminescenceCandidate` | выполнены механический и тепловой критерии |
| `NumericallyInvalid` | расчёт вышел в нефизическое или численно некорректное состояние |

## Текущий лучший кандидат

По текущему прогону лучший найденный режим:

```text
case_id: iter0_axisymmetric_near_collapse_stable_candidate_001
status: ModerateCollapse
frequency: 100000 Hz
drive amplitude: 130480 Pa
R0: 6.0e-6 m
h: 5.0e-7 m
R_min: 1.86897e-6 m
R_max: 2.02216e-5 m
T_max: 6908.2 K
p_g_max: 9.95647e7 Pa
U_max: 151.271 m/s
K_R: 3.21033
K_exp: 3.37026
K_range: 10.8196
M_l: 0.10221
K_h: 3.73794
```

Физическая интерпретация:

- пузырёк расширяется более чем в 3 раза относительно начального радиуса;
- после расширения он схлопывается до радиуса около `1.87 мкм`;
- полный динамический диапазон радиуса равен примерно `10.8`;
- температура газа достигает примерно `6900 K`;
- давление газа почти достигает `1e8 Pa`;
- скорость стенки пузырька достигает примерно `151 м/с`;
- строгий SBSL-критерий пока не выполнен.

Этот режим не является подтверждённой сонолюминесценцией. Но это уже не слабая пульсация, а заметный термомеханический коллапс. Именно поэтому он выделяется как лучший текущий кандидат.

## Модули проекта

### `acoustics/`

Акустический модуль:

- постановка задачи Гельмгольца;
- сборка акустической системы;
- работа с комплексным давлением;
- выборка поля в точках;
- вычисление производных поля;
- расчёт потенциала Горькова;
- поиск точек-кандидатов.

### `bubble/`

Модуль пузырьковой динамики:

- модель Keller-Miksis;
- газовая модель;
- тепловая модель;
- адаптивный ODE-решатель;
- структуры результатов;
- классификация состояния расчёта.

### `coupling/`

Связка акустики и пузырька:

- преобразование комплексного давления в сигнал `p_inf(t)`;
- структуры возбуждения пузырька;
- логика передачи данных из акустического расчёта в ODE-модель.

### `geometry/`

Геометрия:

- построение сосуда;
- построение параболического отражателя;
- разметка источника;
- подготовка физических границ.

### `mesh/`

Сетка:

- работа с Gmsh;
- генерация сетки;
- чтение сетки;
- физические группы;
- граничные теги.

### `io/`

Ввод-вывод:

- чтение YAML;
- запись CSV;
- чтение и запись данных кандидатов;
- экспорт VTK;
- запись временных рядов;
- запись сводок расчёта.

### `postprocess/`

Постобработка:

- расчёт метрик;
- сравнение кандидатов;
- классификация режимов;
- подготовка итоговых таблиц.

## Быстрый запуск

### 1. Расчёт кандидатов Keller-Miksis

```bash
./build/solve_bubble_candidates configs/mid_aggressive.yaml
```

Это основной запуск для проверки текущего поиска кандидатов на коллапс.

Ожидаемые результаты:

```text
results/bubble_km/
├── bubble_results_all.csv
├── best_sbs_candidates.csv
└── timeseries/
```

---

### 2. Решение акустической задачи

```bash
./build/solve_acoustics configs/base.yaml
```

Этот запуск строит акустическое поле и подготавливает данные для анализа и визуализации.

---

### 3. Полный pipeline

```bash
./build/run_pipeline configs/base.yaml
```

Полный запуск выполняет связанный расчёт:

```text
геометрия -> сетка -> акустика -> давление в точке -> пузырёк -> результаты
```

---

### 4. Сканирование частот


## Как читать результаты

Нельзя выбирать лучший режим только по максимальному давлению. Физически хороший кандидат должен одновременно:

1. находиться в разумной акустической области;
2. иметь заметную амплитуду давления;
3. сначала расширяться;
4. затем резко сжиматься;
5. давать рост температуры газа;
6. давать рост давления газа;
7. сохранять численную корректность;
8. не подходить слишком близко к hard-core радиусу.

Поэтому в проекте используются сразу несколько метрик, а не один показатель.

## Ограничения модели

Текущая модель является исследовательским приближением.

Основные ограничения:

- световое излучение напрямую не моделируется;
- форма пузырька считается сферической;
- не моделируются джетинг и разрушение пузырька;
- не учитывается обратное влияние пузырька на акустическое поле;
- не включён массообмен через поверхность пузырька;
- не добавлены водяной пар и химические реакции;
- газовая модель использует сухой аргон;
- акустика и пузырёк связаны односторонне.

Эти ограничения сознательно оставлены на текущем этапе, чтобы сначала выделить главный механизм: акустическое поле вызывает расширение и последующее сжатие пузырька, а это приводит к росту давления и температуры газа.

## Частотный скан, графики и кривизна потенциала Горькова

В текущей версии добавлен отдельный исполняемый файл:

```text
scan_frequency
```

Он делает акустический расчёт не на одной частоте, а на сетке частот. Для каждой частоты программа:

1. читает ту же геометрию и сетку;
2. обновляет `acoustics.frequency_hz`;
3. решает задачу Гельмгольца;
4. считает поле давления;
5. считает градиент давления;
6. считает акустическую скорость;
7. считает потенциал Горькова `U_G`;
8. считает силу Горькова `F_G = -grad U_G`;
9. оценивает тензор кривизны потенциала Горькова;
10. выбирает лучшие точки-кандидаты;
11. сохраняет CSV/VTK по каждой частоте;
12. собирает общий файл `bubble_excitations_all.csv` для последующего запуска Keller-Miksis по всем найденным кандидатам.

### Что означает кривизна потенциала Горькова

Кривизна считается как матрица вторых производных потенциала:

```text
H_G = [ d2U_G/dr2      d2U_G/drdz ]
      [ d2U_G/drdz     d2U_G/dz2  ]
```

В CSV выводятся:

| Поле | Смысл |
|---|---|
| `gorkov_curvature_rr_j_m2` | компонент `d2U_G/dr2` |
| `gorkov_curvature_rz_j_m2` | смешанный компонент `d2U_G/drdz` |
| `gorkov_curvature_zz_j_m2` | компонент `d2U_G/dz2` |
| `gorkov_curvature_trace_j_m2` | след матрицы кривизны |
| `gorkov_curvature_det_j2_m4` | определитель матрицы кривизны |
| `gorkov_curvature_lambda_min_j_m2` | минимальное собственное значение Hessian |
| `gorkov_curvature_lambda_max_j_m2` | максимальное собственное значение Hessian |
| `gorkov_curvature_positive_definite` | признак положительной определённости |

Физическая интерпретация в текущей модели такая: положительная кривизна около минимума `U_G` означает локальную акустическую ловушку по координатам пузырька. Это не является прямым критерием радиального схлопывания, потому что координаты пузырька описывают положение центра, а не радиус. Поэтому кривизна используется как дополнительная метрика устойчивости положения кандидата, а финальный вывод о коллапсе делается по Keller-Miksis.

### Быстрый полный запуск

Из корня проекта:

```bash
chmod +x scripts/run_frequency_scan_pipeline.sh
./scripts/run_frequency_scan_pipeline.sh configs/base.yaml 20000 200000 25 10
```

Параметры команды:

```text
configs/base.yaml     конфиг расчёта
20000                 минимальная частота, Гц
200000                максимальная частота, Гц
25                    число точек частотного скана
10                    число кандидатов Горькова на каждой частоте
```

После выполнения результаты будут лежать в каталоге вида:

```text
results/frequency_scan_20000_200000_25
```

### Ручной запуск по шагам

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j --target build_geometry scan_frequency solve_bubble_candidates

mkdir -p results/frequency_scan

./build/build_geometry configs/base.yaml results/frequency_scan/mesh.msh

./build/scan_frequency \
  configs/base.yaml \
  results/frequency_scan/mesh.msh \
  results/frequency_scan \
  20000 \
  200000 \
  25 \
  10 \
  0

./build/solve_bubble_candidates \
  configs/base.yaml \
  results/frequency_scan/bubble_excitations_all.csv \
  results/frequency_scan/bubble_results_all.csv \
  results/frequency_scan/timeseries

python3 scripts/plot_frequency_scan.py \
  results/frequency_scan \
  results/frequency_scan/bubble_results_all.csv
```

Последний аргумент `0` у `scan_frequency` означает, что псевдообъёмный VTK не строится. Если нужен 3D-псевдообъём для ParaView, можно поставить, например, `48`:

```bash
./build/scan_frequency configs/base.yaml results/frequency_scan/mesh.msh results/frequency_scan 20000 200000 25 10 48
```
